# ورشة بيانات ورتّل

أداة محلية مستقلة لتحرير ملفات المساهمة. لا تحتاج React أو `npm` أو خادمًا، ولا تحتوي على شفرة التطبيق الخاص. افتح `public/builder/index.html` في Chrome أو Edge على جهازك، ثم اختر **المجلد الجذر** لنسختك من هذا المستودع. إذا رفض المتصفح قراءة المجلد، جرّب أحدث Chrome أو Edge؛ اختيار المجلد مطلوب لأن الآيات والصور تُقرأ كملفات محلية مرجعية.

الأقسام المتاحة: قواعد التحدي، الموضوعات والمسارات ووسوم السور، البحوث المحفوظة، مشاهد السينما وقوالبها، استبعادات التصفح وخلفياته، وصور الوجه الخلفي وربطها بالآيات. مربع معاينة الآية يقرأ النص من `src/data/verses/` **دون تعديله**. `metadata.json` يُقرأ فقط للتحقق من أرقام السور والآيات؛ لا يملك محررًا. ملفات النص والهيكل والصوت ومفاتيح ميزات الإنتاج خارج نطاق التحرير.

## كيف تحفظ مساهمتك؟

1. عدّل ما تريد في الورشة. عبارة **مسودة** تعني أن الملفات الأصلية لم تتغير. قبل إغلاق الصفحة، نزّل حزمة المراجعة؛ المسودة الموجودة في الذاكرة وحدها تضيع عند إعادة التحميل.
2. اضغط **فحص الملفات**. يجب معالجة الأخطاء قبل التصدير. يمكن ترك تحذير قديم موضّح للمراجع إذا لم يكن جزءًا من مساهمتك؛ لا تُخفِه أو تُصحّحه تلقائيًا.
3. اضغط **تنزيل حزمة المراجعة**. سيُنزل ملف ZIP واحد فيه `backup/` (نسخ بايت-ببايت من ملفات JSON الأصلية التي غيّرتها)، و`proposed/` (ملفات JSON المقترحة والصور الجديدة)، و`REVIEW.txt` (قائمة موجزة). هذا تنزيل إلى جهازك **وليس كتابة تلقائية في المستودع**.
4. افتح الحزمة وقارن `backup/` مع `proposed/`. بعد التأكد، انسخ محتويات `proposed/` وحدها إلى جذر فرعك، مع الحفاظ على المسارات. لا تنسخ `backup/` إلى فرع المساهمة.
5. راجع فرق Git وقدّم طلب سحب صغيرًا مع سبب تعليمي ومصادر أي صورة أو علاقة قرآنية. لا تنشر صورًا لا تملك حق استخدامها.

إذا أردت التراجع، انسخ الملف المقابل من `backup/` إلى مساره الأصلي في نسختك المحلية. يمكن أيضًا إلغاء المسودة بإعادة تحميل الصفحة لأن الورشة لا تكتب في ملفات المصدر. وجود النسخة الأصلية داخل ZIP لا يغني عن مراجعة Git أو النسخ الاحتياطية المعتادة للكمبيوتر.

الصور الجديدة تُحوّل محليًا إلى WebP، بحجم لا يتجاوز 5 ميغابايت. المقاس العمودي 1080 × 1920 نقطة بداية، وليس شرطًا. المعاينة تقريبية؛ افحص وضوح كل حرف وتشكيل في التطبيق على الهاتف والكمبيوتر قبل طلب دمج التصميم. لا تضع أسرارًا أو ملاحظات مستخدمين في ملفات المساهمة.

## فحص المطور

من جذر المستودع: `node --test public/builder/tests.cjs`. يستخدم هذا الفحص المكتبات المدمجة في Node فقط ولا يغير ملفات البيانات. الصفحة نفسها لا تتصل بخادم محلي أو بخدمات التطبيق؛ أي فيديو خارجي تختاره يظهر كرابط بيانات في JSON، ولا تُحمّله الورشة تلقائيًا.
